# Adaptive Multi-Source End-to-End Communication System

## Overview

This project implements an intelligent adaptive communication system capable of processing multiple signal types:

- Clean Signal
- AM Signal
- FM Signal
- Noise Signal
- AM + Noise
- FM + Noise

The system automatically detects signal type and selects appropriate processing techniques.

## Features

- Automatic Signal Classification
- Adaptive Filtering
- AM/FM Demodulation
- ADC & DAC Processing
- Error Control Coding
- BER Analysis
- Adaptive Feedback System
- ESP32 Sensor Integration

## Technologies Used

- MATLAB
- ESP32
- Arduino IDE
- Digital Communication Techniques

## Hardware Used

- ESP32

- Wireless Communication
- IoT Systems

- Adaptive Signal Processing
